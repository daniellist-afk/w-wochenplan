# W-Wochenplan – iPhone-Web-App

Web-Version der Mac-App „W-Wochenplan“. Liest und schreibt die `wochenplan.json` direkt im eigenen Google Drive (Ordner „W-Wochenplan“).

Eigene Kopie: Repository forken, GitHub Pages einschalten, eigene OAuth-Client-ID anlegen – beim ersten Start fragt die App danach.
